These shorthand names always refer to the immutable files in `data/raw/bass_ii/original/`, with hashes in the [manifest](../data/manifests/bass_ii_acquisition_manifest.json). CSV rows include the header (B1 is row 2). Worksheet references preserve actual names, including `T'ien`.

FAQ page references use the file's saved Word pagination, not a new render: six `lastRenderedPageBreak` markers agree with seven pages in document properties. Exact paragraph IDs and complete text are in the [extraction](source_extracts/bass_ii_readme_extracted.md). Fresh rendering was unavailable because LibreOffice was not installed. The user-supplied filenames and expected portal aliases are recorded separately; hash agreement is with user-provided baselines, not an independently published NASA checksum.

The three sources are locally verified and all 129 records reconcile. This dictionary replaces provisional field semantics with the cited FAQ definitions while preserving the former document in [history](history/m2b2_before_reconciliation/bass_ii_data_dictionary.md). It is an evidence-backed engineering dictionary, not scientific validation.

## Source preservation and semantic annotations

The existing parser still emits exact CSV header/value strings and lexical classifications. Keep its output unchanged. A future semantic annotation may say `OR` means greater than 1000 ppm with FAQ p. 2 paragraph 25 evidence, while the parser's raw classification remains `ambiguous_token`. `over` remains unresolved. Censored bounds are not exact values; negative readings remain signed values with review flags; blank and none remain distinct source markers; recorded zero is not missing.

No automatic material filling, suffix stripping, date repair, unit conversion, airflow inference or numerical reduction of sequences is permitted by this audit. Where voltage-display identity is confirmed, the FAQ's display/10 relationship describes volts only; the ambiguous Fan display column must not be divided wholesale. Air cm/s applies to identified air-speed tokens, not embedded potentiometer annotations. Gain has no calibrated intensity unit. Gas unit labels remain `% by vol` and `ppm` exactly as sourced; CO ppm basis is not specified.

## Proposed normalized entities (design only)

| Entity | Source-preserving fields and mapping |
| --- | --- |
| Investigation | source_id=PSI-25; DOI=10.60555/4qc4-de67; source page and observed portal version separate from the unknown downloaded-file version. |
| Experiment | source_row_id, exact PI/Test #/Sample #, date_raw, gmt_raw, frame_count_raw; link exact CSV row to exact workbook sheet/C/D cells. Sample reuse and a/b suffixes never imply independence. |
| Condition | original_variable_name/value/unit; material description and configuration/display cells; optional reviewed semantic annotations with source spans. Never replace the complete raw strings. |
| Measurement | original gas column/value/unit; source initial/final phase; optional reviewed numeric or censored interpretation; missing-kind and unresolved status. No generated phase timestamps or calibration coefficients. |
| ResearchDocument | actual filename, expected portal alias, hash, bytes, supplied path, source page, source identity scope, structural/content status; filename alias is not an independently verified portal-byte identity. |
| Evidence | document hash + saved page/paragraph, workbook hash + sheet/cell/header, or CSV hash + Test # + row/column. Preserve direct statement separately from reconciliation and engineering decisions. |
| DataProvenance | investigation/test ID; exact source filename; URL (nullable actual download URL); original variable/value/unit; extraction method; location; verification status/scope; verification time separate from unknown retrieval time. |
